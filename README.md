# Python Problem Solving — 30 Challenges

A structured collection of **30 Python problem-solving exercises** created to strengthen programming fundamentals, logical thinking, and problem-solving skills.

This repository focuses on understanding the logic behind each problem rather than simply memorizing solutions.
